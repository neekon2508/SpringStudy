# Extensions for Spring Boot backend and ReactJS frontend

1. Extension Pack for Java​

Extension ID: vscjava.vscode-java-pack​

- Essential extension packs for Java development (including Language Support, Debugger, Test Runner, etc.)​

- Installation: `code --install-extension vscjava.vscode-java-pack`​

​
